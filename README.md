# SQL EXERCISES

## Overview

This repository contains solutions to SQL exercises from various sources. The sources include:
- The book *"Practical SQL: A Beginner's guide to storytelling with data"* by Anthony DeBarros.
- The website [DataLemur](https://datalemur.com/questions?category=SQL), which features a variety of SQL questions.

All the solutions use PostgreSQL. Each source has its own directory and includes solutions covering various SQL topics and difficulty levels.

This repository is intended for learning, practicing and reviewing SQL through progressively more complex challenges.

## SQL Topics Covered

The SQL topics covered include:
- Basic query clauses: `SELECT`, `FROM`, `WHERE`, `GROUP BY`, `ORDER BY`, `HAVING`, `DISTINCT`
- Aggregate functions: `SUM`, `COUNT`
- Joins
- Date and time manipulation
- Conditional logic with `CASE ... WHEN`
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions: `ROW_NUMBER()`, `DENSE_RANK()`, `LAG()`
